Entry for the make.fun bounty "The Funniest Office Joke, Judged Head to Head": one short line about office life, judged pairwise by an AI judge. The joke turns on the calendar invite everyone recognises — ask for balance, get a recurring meeting about it, and discover your own attendance was optional all along.

> I asked my calendar for work-life balance; it reply-all'd a recurring 9am 'Synergy Alignment' and marked my attendance optional.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, single line). Python 3.13, standard library only, no network.
